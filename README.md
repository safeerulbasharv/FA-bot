# Fas_choice 🧠💬

Fas_choice is a Django-based web application that includes a chatbot feature.  
This project is built using **Python** and **Django**, with a simple SQLite database for development.

---

## 🚀 Features

- Django-powered backend
- Chatbot application module
- SQLite database (default)
- Easy local setup
- Modular Django app structure

---

## 🛠️ Tech Stack

- **Python 3**
- **Django**
- **SQLite3**
- **HTML / CSS** (frontend templates)

---

## ⚙️ Installation & Setup

### Create Virtual Environment
```bash
cd FA-bot
python -m venv venv
venv\Scripts\activate  #Windows
```
### Install Dependencies
```bash
pip install django
pip install nltk
```
### run server
```bash
python manage.py migrate
python manage.py runserver
```
